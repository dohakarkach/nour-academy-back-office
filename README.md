# NourAdmin — Back-office du secrétariat

Application web de gestion interne de Nour Academy, réseau de trois centres de soutien scolaire et de langues à Nador. Le back-office permet au secrétariat de consulter et de gérer les inscriptions des élèves, de suivre les paiements et de visualiser les statistiques de l'activité.

## Fonctionnalités

- Tableau de bord : affichage du nombre total d'inscriptions, des dossiers en attente, validés et payés, ainsi que des recettes encaissées.
- Remplissage des cours : visualisation du nombre d'élèves inscrits par rapport à la capacité maximale de chaque cours.
- Gestion des inscriptions : consultation des dossiers avec les informations des élèves, des parents, des cours choisis et du statut de chaque inscription.
- Recherche : recherche instantanée d'un dossier par nom d'élève ou numéro de téléphone du parent.
- Filtrage : affichage des inscriptions selon leur statut (En attente, Validée ou Payée).
- Tri : classement des inscriptions par nom ou par date, dans l'ordre croissant ou décroissant.
- Persistance des données : sauvegarde des inscriptions dans le navigateur avec localStorage et conservation des critères de recherche et de filtrage pendant la session avec sessionStorage.

## Technologies

HTML5 sémantique, CSS3 natif (Flexbox, Grid, variables CSS et responsive design) et JavaScript natif avec modules ES6. Aucune bibliothèque ni aucun framework JavaScript.

## Design

Interface responsive avec un thème sombre, une navigation latérale rétractable et un tableau de bord composé de cartes statistiques. L'application est conçue pour s'adapter aux écrans d'ordinateur, de tablette et de téléphone.

## Stockage des données

Les données sont stockées localement dans le navigateur. Aucune API ni aucun serveur backend n'est utilisé dans cette version du projet.
